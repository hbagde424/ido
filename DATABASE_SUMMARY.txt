📋 IMPORTANT QUERIES
===============================================

1. View all policies:
SELECT * FROM essentials_policies;

2. View Company Policy records:
SELECT * FROM essentials_policies 
WHERE policy_type = 'company_policy';

3. View Leave Policy records:
SELECT * FROM essentials_policies 
WHERE policy_type = 'leave_policy';

4. View HR Policy records:
SELECT * FROM essentials_policies 
WHERE policy_type = 'hr_policy';

5. View policies by user:
SELECT * FROM essentials_policies 
WHERE user_id = 1;

6. View signed policies:
SELECT * FROM essentials_policies 
WHERE status = 'signed';

7. View pending policies:
SELECT * FROM essentials_policies 
WHERE status = 'pending';

8. Count policies by type and status:
SELECT policy_type, status, COUNT(*) as count
FROM essentials_policies
GROUP BY policy_type, status;

9. View users who signed policies:
SELECT u.first_name, u.last_name, ep.policy_type, ep.status
FROM essentials_policies ep
JOIN users u ON ep.user_id = u.id
ORDER BY ep.policy_type;

10. View content length:
SELECT policy_type, LENGTH(content) as content_length
FROM essentials_policies
GROUP BY policy_type;
